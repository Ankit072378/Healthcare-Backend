HEALTHCARE BACKEND REST API

A secure and scalable Healthcare Backend REST API built using Node.js, Express.js, PostgreSQL, and Sequelize ORM. The system provides JWT-based authentication, patient and doctor management, patient-doctor mappings, input validation, centralized error handling, and automated API testing.

Features

JWT-based user authentication

Secure password hashing with bcrypt

Patient CRUD operations

Doctor CRUD operations

Patient-Doctor mapping

Input validation

Centralized error handling

PostgreSQL database with Sequelize

Jest & Supertest API testing

Postman collection with automatic JWT token handling

TECH STACK

Node.js | Express.js | PostgreSQL | Sequelize | JWT | bcryptjs | Jest | Supertest
